# 类型判定与主要矛盾

**页面类型**:产品工作区(服务器管理驾驶舱)——非说服型,无转化诉求,高频工具页。

**主要矛盾**:全服态势一眼可判 vs 五类指标的信息洪流。

推导:服主打开页面的第一问永远是"服务器现在正常吗"——这个问题必须 5 秒内、不滚动、不读数字就能回答(颜色先行:全绿=健康,一处黄=该看一眼,一处红=出事了)。所有区块的层级服从这个答案速度,装饰性信息(版本公告、banner)一律不上。

**次级张力**:MC 原版视觉(为沉浸游戏内 UI 设计,密度低、字号小)vs 数据密度需求(驾驶舱要看很多数字)。处置:保留原版的**材质语言**(面板立体边/槽位/按钮三态/tooltip 渐变),但布局节奏按工具页需要放大呼吸感——不是复刻游戏内某个界面,而是用原版材质语言造一个游戏里没有的界面。此决策依据基线"不是复刻游戏内某个界面,而是用原版材质语言造界面"的精神,与需求书"1 GUI px=3 CSS px"约束共同收敛为:**控件级像素严格复刻,布局级自由编排**。

**对标差异检验**(challenge 第 2 维,镜像测试):市面上 MC 服务器面板(Pterodactyl 等)全部是现代扁平后台风——右侧栏+白卡+ECharts。本页反着走:MC 原版材质贯穿,同类产品不会长这样,差异化成立。
