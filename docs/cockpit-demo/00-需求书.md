# 需求书 · MC 服务器管理驾驶舱(Web 版)

> 任务编号:cockpit-demo · 日期:2026-11-09 · 类型:编造的实战校准需求(用户指令:"用 mc",放 GitHub 公开展示)

## 背景与用户

Minecraft 1.7.10 模组服服主需要在游戏外管理服务器:看在线人数、TPS 健康、玩家动态、执行日常操作。现有方案是裸控制台敲命令,状态全靠脑记。

**用户**:模组服服主(技术型,中文)。
**场景**:桌面 1280×800 主视口(与技能首屏判定基准一致);双屏副屏常驻(信息密度可偏高)。

## 功能范围

1. **状态 KPI 条**:在线人数/10、TPS(20 为满)、内存占用、平均延迟——超阈值变警示色
2. **在线趋势**:近 2 小时在线人数直方图(像素风,5 分钟粒度)
3. **玩家表**:当前在线玩家(名字/延迟/血量饱和度/所在维度),支持点击弹 MC 风格 tooltip
4. **快捷操作区**:公告/传送/白名单/备份四组按钮(widgets.png 三态规格)
5. **控制台日志流**:最近 40 条,INFO/WARN/ERROR 分级着色,等宽字体

## 视觉约束(基线:assets/design-md/minecraft/DESIGN.md)

- **1 GUI px = 3 CSS px** 绝对像素定位;槽 18×18 网格节奏;容器 176×166 系比例
- 原版禁则:无圆角/无粗体/无字距/无投影滤镜;按钮 = widgets.png 三态渐变复刻
- 面板 #c6c6c6 外凸立体边,槽位内凹边;tooltip 用原版渐变规格
- MC 字体观感(等宽/点阵感),中文宽度按实际渲染不硬猜

## 数据

模拟快照(服务器未接入,需求书明示标注):人数/TPS/内存曲线 24 点,玩家 8 人,日志 40 条。页面脚注标注"演示数据,接入 rcon/bridge 后为实时值"。

## 验收标准

- 5 秒内不滚动可判:服务器健康吗、谁在线、有无异常日志
- 全部控件落在 3px 网格(1 GUI px);截图 lint ❌ 级清零或按还原优先豁免并注明
- 独立评审(隔离上下文)通过;8 维矩阵终检归档
- 全流程留档本目录

## 明确不做

真实 rcon 接入、移动端、多服务器、权限体系、暗色模式(MC 视觉即深浅混合体系)。
