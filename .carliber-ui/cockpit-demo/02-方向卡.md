# 方向卡

**北极星**:一眼知健康,三击达操作。

**方向**:原版材质工具化——把 Minecraft 的容器美学(灰色面板、立体槽位、widgets 按钮)当设计系统用,做一个"游戏里不存在的原版界面"。信息层级:状态颜色(语义绿黄红)是第一层,区块空间位置是第二层,文字数字是第三层。

**首屏结构**(1280×800 不滚动判定区,与技能基准一致):
```
┌─ 顶部标题条(面板立体边,server 名 + 在线人数大数字)────────┐
│ KPI 条:在线 ▏TPS ▏内存 ▏延迟(4 块槽位式指标,阈值变色)      │
│ 在线趋势直方图(28 柱,2 小时)          ▏控制台日志(右半,40 条)│
│ 玩家表(8 行,槽位行样式)               ▏(日志占右半同高)      │
│ 快捷操作:公告/传送/白名单/备份(widgets 按钮 ×4)              │
└──────────────────────────────────────────────┘
```

**色彩令牌**(全部出自基线,零新色):
面板 #c6c6c6 / 槽 #8b8b8b / 亮边 #ffffff / 暗边 #555 / 内凹 #373737 / 文字 #404040·#e0e0e0
语义层借用基线授权的三色:进度填充 #7fd47f(健康)、tooltip 黄 #ffffa0(注意)、error #c64545→按原版红石色 #d1462f(警示,像素语境手调并注明)
日志分级:INFO #404040 / WARN #b8860b / ERROR #c64545

**字体**:中文 "PingFang SC" 栈(可读优先,MC 点阵字体无中文版,基线注明中文宽度实测原则);数字/日志 Consolas 等宽。

**关键状态**:TPS<18 变警示色;玩家人数 0 时空态文案"服务器空闲中,猫在后台睡觉"(真实产品语气的空态);日志 ERROR 行整行淡红底。

**验收重点**:像素网格严格(3px 整倍数)、三态按钮悬停手感、颜色即状态的响应速度。
