# 数据可视化

返回 [主入口](../SKILL.md)。页面里出现图表、指标卡或数据对比时读。只管可视化层的判断,数据怎么来、怎么算不在本文件。

## 先决定用不用图

- **反复浏览同类对象用稳定列表,需要比较时才并列,需要看趋势/分布/构成时才用图**——主流程步骤 2 已定;没有比较诉求的指标,一个大数字加说明胜过一张饼。
- 一屏图表超过三张时,先问哪个决策在看这些图,删到答案只剩支撑那个决策的。
- "侧栏+指标卡+折线+表格"不是默认答案,也不为反模板禁用合理组件。

## 用色

- **不靠颜色单独传义**:红绿、同系多色只用颜色区分时,加形状、标签、直接标注兜底(色盲与黑白打印下仍可读)。验证方法:页面注入绿色盲滤镜后看图复核,`<feColorMatrix type="matrix" values="0.625 0.375 0 0 0  0.7 0.3 0 0 0  0 0.3 0.7 0 0"/>` 挂 `html{filter:url(#cb)}`;模拟下仍可辨即可,不可辨加形状第二通道(如峰值柱加顶帽)。
- 序列色从项目主色衍生,数量 ≤6,多了合并为"其他";语义色沿用项目规范(如 Miracle 基线的 success/danger),不自造第二套。
- 高亮只点关键的一两处(峰值、预警),其余退灰——与界面用色同一个"单点信号高亮"逻辑。
- **同轴多系列量级兼容**:任一系列的最大值超过最小系列最大值的 3 倍时,小系列会被压扁失去可读性——分图、双轴或默认隐藏(图例可开并在图例上标明量级差异)。累计量与日增量不共轴。
- **低饱和系列色需要底色对比**:灰系系列段放在接近色的面板底上会消失——图表区垫中性深底,或段间加对比色分隔缝,不靠颜色单独承载分段信息(白缝+位置+图例兕底)。
- 大面积用低饱和底色,高饱和只给小面积焦点;图表底色跟容器走,不另开画布色。

## 图例、标注与 tooltip

- **关键数值直接标在数据旁边**,不让人在图例和图形间来回对色;图例只在不直接标注时用。
- tooltip 显示完整值+单位+时间,不只是截断的短串;悬停目标包含点、条和间隙(整条行命中)。
- 坐标轴单位写清楚(万元、人次、%),轴标签不省略成裸数字;轴起点非零时明示,不裁剪制造夸大差异。

## 中文标签

- 轴标签、图例文字过长时先考虑换行或缩写,**不旋转 45° 硬塞**;日期/编号用等宽字体(排版细则见 [中文排版](typography-zh.md))。
- 数字用 tabular/等宽对齐,千分位按项目惯例;同一图内单位与小数位保持一致。

## 状态完整

- **空态**(无数据):给一句"为什么没有/怎么会有",不是空白坐标轴。
- **零值与缺失分开**:零是数据,"—"才是没有;单点不画趋势线,只画点。
- **极端值**:离群点标注或截断时注明,不让一个极值把其余压成直线。

## 形式纪律

- 不用 3D 饼、阴影立体、渐变填充这类装饰;网格线退到最淡,数据墨水比优先。
- 动效只用于追踪变化(悬停联动、增量过渡),不为出场炫技;遵守基线里的动效禁则(如 MC 原型无 CSS 过渡)。
- 用成熟图表库(ECharts、Chart.js 等)时改主题到项目色板,不用默认配色直出。
