# 多轮对比收敛

返回 [主入口](../SKILL.md)。默认一轮独立评审、修完就交付;只有任务本身以"打磨到极致"为目标时才进入多轮。多轮不是把同样的评审重复几遍,而是每轮都有明确的收敛对象和停止条件。

## 何时进入多轮

满足任一:

- 用户说"打磨到极致""多轮对比""再精一版",或点名要反复推敲
- 任务是单个组件做到有辨识度(见主流程"选择范围"对应行)
- 首轮评审低于 7 分且用户要求继续改

用户没说、时间紧、无人值守 → 不进入,按一轮交付。

## 一轮的结构

改 → 截图 → 并排对比 → 三问 → 评分:

1. 只修本轮认定的对象(即上一轮三问的第三问),不顺手改别的。
2. 截当前状态图,与上一轮成品**并排**放在一处(对比页或文档里两图相邻);不在只看新版的情况下打分,改了什么要与上一版对照着看。
3. 三问,各答一句:
   - 变好了什么?
   - 变差了什么(修 A 伤了 B 的地方)?
   - 下一轮只修什么?
4. 10 分制评分,记本轮分与上一轮的分差。

每轮跑一遍 [多维质疑矩阵](challenge.md) 里上一轮暴露过的 ❌ 维度,确认修复没有在别的维度欠新账。

## 停止条件(满足其一即停)

- 评分 ≥ 8.5 且矩阵无 ❌。
- 连续两轮分差 < 0.5 且没有新发现的问题。
- 到达轮次上限:默认 3 轮(含首轮评审),用户指定时服从用户。

到上限仍有 ❌:照实交付,❌ 清单写进"哪些没做、为什么",不假装收敛。

## 防振荡

- 同一处连续两轮来回改(改回去又改回来)→ 停下,并排两版让用户挑,或按设计说明的北极星定夺。
- "修 A 伤 B"反复出现 → 问题在结构不在样式,退回灰度结构层面重排,不在细节上拉锯。
- 每轮记一行:轮次 / 改了什么 / 三问答案 / 分数。全部轮次记录留在任务目录(建议 `rounds.md`),交付说明只引结论,不贴全过程。
